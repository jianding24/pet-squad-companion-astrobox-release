# 萌宠营地 AstroBox 发布资源

版本：1.0.1，构建14。免费配套表盘；联动已激活的萌宠归队，随游戏进度解锁更多内容。

本仓库仅存放安装包、商店图片、介绍和资源清单，供AstroBox首次添加资源申请使用；资源仓库公开不代表已通过审核或上架。

- `manifest_v2.json`：介绍、版本、设备映射和下载路径。
- `downloads/`：各档位FACE安装包和同名INFO记录。
- `media/`：与应用相同的三宠图标、主封面和6张带设备轮廓的内容图。
- `详情文案.txt`：完整介绍和配套应用引导链接。
- `files.json`：上述发布文件的SHA-256摘要。
